SPYDER / 선수 명단 관리자 ← 사이트로 돌아가기

[ 01 ] 분류 항목 설정

이름·소속 외에 관리할 분류 항목입니다. 기본값은 체급/연령/성별이며, 자유롭게 추가·삭제·이름 변경이 가능합니다. 항목 순서가 아래 엑셀 붙여넣기 열 순서가 됩니다.

[ 02 ] 엑셀로 등록

엑셀 파일(.xlsx/.csv)을 첨부하거나, 아래 순서의 열을 복사(Ctrl+C)해 텍스트 상자에 붙여넣으세요(Ctrl+V). 헤더(제목) 행은 자동으로 인식해 건너뜁니다.

[ 03 ] 현재 등록된 선수 명단

셀을 직접 클릭해서 수정할 수 있습니다. 편집 중인 내용은 이 화면에만 있으며, [04]의 "지금 사이트에 반영하기"를 눌러야 실제 사이트에 저장됩니다.

[ 04 ] 게시 / 불러오기

지금 사이트에 반영하기 버튼을 누르면 실시간으로 명단 페이지에 즉시 반영됩니다(새로고침 불필요). JSON 다운로드는 백업 용도입니다.

편집 중인 내용은 반영하기 전까지 실제 사이트에 영향이 없습니다.
