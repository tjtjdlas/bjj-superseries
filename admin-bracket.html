[ 03 ] 대진 자동 생성

전체 재생성은 현재 초안의 선수 배치와 입력된 경기 결과를 모두 새로 만듭니다(직전 초안은 자동 백업). 경기번호·매트·예상시간만 다시 맞추려면 오른쪽 버튼을 사용하세요.

[ 03-B ] 엑셀 대진 붙여넣기 · 업로드

엑셀에 1회전 대진을 직접 그려 넣은 뒤 그대로 가져오는 방식입니다. 한 행이 한 경기(선수 2명)이고, 위에서부터 적은 순서가 대진도의 위→아래 순서가 됩니다. 8강·4강·결승 등 다음 라운드와 승자 전파는 사이트가 자동으로 이어 만듭니다.

[ 04 ] 부문 · 경기 직접 편집

선수 배치(1회전), 경기번호, 매트, 예상 경기 시간, 경기시간(분), 진행 상태, 승자와 점수를 직접 수정할 수 있습니다. 승자를 선택하면 다음 라운드에 자동 반영되며, 이전 결과를 바꾸면 이후 라운드 결과는 자동으로 무효화됩니다.

[ 05 ] 미리보기 (공개 화면과 동일)

현재 편집 중인 초안 기준입니다. 게시 전까지 공개 화면에는 노출되지 않습니다.

[ 06 ] 저장 · 게시 · 내보내기
