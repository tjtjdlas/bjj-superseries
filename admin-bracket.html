① 대진표 엑셀 올리기

대진표 엑셀(스파이더 대진표 양식)을 그대로 첨부하세요. 시트 1개가 부문 그룹(중등부·고등부·어덜트 …)이 되고, 각 부문 제목 아래 선수 칸(이름/소속, 부전승, "1경기 패자")을 위→아래 순서대로 읽어 2·4·5·8·10인 대진과 A·B조 결승을 엑셀과 같은 모양으로 만듭니다. 시트의 "게임수"와 실제 경기 수도 비교해 알려 줍니다.
첨부하면 바로 검증 결과가 나오고, 결과 아래 [검증 결과 초안에 반영]을 눌러야 초안에 들어갑니다.

또는 엑셀 셀 범위 붙여넣기 (행 양식 · 한 행 = 1회전 한 경기)

엑셀에 1회전 대진을 행으로 적은 양식은 셀 범위를 복사해 붙여넣거나 파일로 첨부할 수 있습니다. 위에서부터 적은 순서가 대진도의 위→아래 순서가 되고, 8강·4강·결승 등 다음 라운드와 승자 전파는 사이트가 자동으로 이어 만듭니다.

② 초안 확인

현재 초안을 공개 화면과 같은 모양으로 확인합니다. 게시 전까지 공개 화면에는 나오지 않습니다.

③ 사이트에 게시

게시를 누르면 공개 대진표 페이지에 바로 반영됩니다. 초안 저장은 공개 화면을 바꾸지 않고 서버에만 보관합니다.

불러오는 중…

대회 당일 결과 입력 · 부문 직접 편집승자·점수·진행 상태 입력, 선수 배치·매트·경기시간 수정

선수 배치(1회전), 경기번호, 매트, 예상 경기 시간, 경기시간(분), 진행 상태, 승자와 점수를 직접 수정할 수 있습니다. 승자를 선택하면 다음 라운드에 자동 반영되며, 이전 결과를 바꾸면 이후 라운드 결과는 자동으로 무효화됩니다. 입력한 뒤 ③에서 [지금 사이트에 게시하기]를 눌러야 공개 화면에 반영됩니다.

고급 기능참가자 명단으로 대진 자동 생성 · 대진 설정 (엑셀로 대진을 올릴 때는 쓰지 않음)

참가자 명단 연동
